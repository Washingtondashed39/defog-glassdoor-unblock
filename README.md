### Step 3: Extract the File

### Step 7: Verify Installation

The extension should now appear in your list of installed extensions. You'll also see its icon in the top-right toolbar of your browser (it looks like a small eye or shield icon).

## 🛠️ Troubleshooting Common Issues

### The extension doesn't seem to work

- **Refresh the page** – Press `F5` or click the refresh icon. The extension applies when the page loads.
- **Check your browser version** – Make sure Chrome or Edge is updated to the latest version.
- **Restart your browser** – Close all browser windows and reopen them.

### I can't find the "Load unpacked" button

- Make sure **Developer mode** is toggled ON (Step 5).
- If you still don't see it, close and reopen the Extensions page.

### The extension disappeared after a browser restart

- This can happen if you moved the extracted folder. Keep the folder in a permanent location.
- Re-load the extension using Steps 5–6 if needed.

### Glassdoor changed their layout

- If Glassdoor updates its website, the extension may stop working temporarily. Visit the GitHub page to check for updates.
